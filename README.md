# Portafolio web — Estética victoriana e inspiración Monet

## Objetivo
Presentar un portafolio profesional adaptable con perfil, tecnologías, 9 proyectos filtrables, experiencia, videos de YouTube, formulario de contacto, redes sociales y modo claro/oscuro. El diseño combina inspiración victoriana, flores impresionistas y una animación sutil de caracteres/pétalos.

## Tecnologías
- HTML5, CSS3, Bootstrap 5 y JavaScript en `index.html`
- Font Awesome para iconos
- YouTube en iframes responsivos
- EmailJS puede conectarse para el envío automático del formulario

## Personaliza antes de entregar
Abre `index.html` en Visual Studio Code y reemplaza `Tu Nombre`, título, biografía, experiencias, proyectos, imagen y enlaces sociales `#` por tus propios datos. Las tarjetas actuales son ejemplos, no deben presentarse como experiencia real.

## Formulario de contacto
La versión inicial prepara un correo mediante la aplicación de correo del visitante. Para cumplir el requisito de envío real automático, configura una cuenta en https://www.emailjs.com/ y sigue su documentación oficial. No publiques contraseñas ni claves privadas. Si tu profesor exige el mensaje exacto “Mensaje enviado correctamente”, muestra ese mensaje solo después de que EmailJS confirme el envío.

## Ver la página local
Haz doble clic en `index.html`. Bootstrap, Font Awesome, fuentes e imágenes remotas requieren conexión a Internet.

## Publicar en GitHub Pages sin comandos
1. Entra en https://github.com/ y crea una cuenta o inicia sesión.
2. Pulsa `+` → `New repository`.
3. Nombre sugerido: `portafolio-victoriano-monet`; selecciona `Public`.
4. Crea el repositorio.
5. Pulsa `Add file` → `Upload files`.
6. Arrastra `index.html`, `README.md` y `LICENSE` al área de carga y pulsa `Commit changes`.
7. En el repositorio abre `Settings` → `Pages`.
8. En `Build and deployment`, elige `Deploy from a branch`.
9. Selecciona rama `main` y carpeta `/(root)` y pulsa `Save`.
10. Espera unos minutos y abre la URL que GitHub muestre. Añade esa URL real al README.

## Publicar también en Vercel
1. Entra en https://vercel.com/ y pulsa `Continue with GitHub`.
2. Elige `Add New` → `Project`.
3. Importa el repositorio y pulsa `Deploy`.
4. Guarda la URL real que Vercel te proporcione.

## Comparación breve
- **GitHub Pages:** publica un sitio estático desde el repositorio GitHub y resulta directo para proyectos académicos.
- **Vercel:** integración con GitHub, despliegues automáticos y vistas previas para cambios.
- Ambos pueden alojar este sitio estático. Compara los tiempos que observes en tu propia prueba.
