# Portafolio web — Estética victoriana e inspiración Monet
 https://genekristi.github.io/portafolio-victoriano-monet/

 
Objetivo
Presentar un portafolio profesional adaptable con perfil, tecnologías, 9 proyectos filtrables, experiencia, videos de YouTube, formulario de contacto, redes sociales y modo claro/oscuro. El diseño combina inspiración victoriana, flores impresionistas y una animación sutil de caracteres/pétalos.

Tecnologías
- HTML5, CSS3, Bootstrap 5 y JavaScript en `index.html`
- Font Awesome para iconos
- YouTube en iframes responsivos
- EmailJS puede conectarse para el envío automático del formulario


Publicar en GitHub 
1. Entra en https://github.com/ y crea una cuenta o inicia sesión.
2. Pulsar `+` → `New repository`.
3. Nombre: `portafolio-victoriano-monet`; selecciona `Public`.
4. Crea el repositorio.  <img width="1366" height="768" alt="Captura de pantalla (793)" src="https://github.com/user-attachments/assets/5d5d06b2-b127-4e11-866e-f4e1fdda7aa7" />
5. Pulsa `Add file` → `Upload files`.
6. Arrastra `index.html`, `README.md` y `LICENSE` al área de carga y pulsa `Commit changes`.
<img width="1366" height="768" alt="Captura de pantalla (796)" src="https://github.com/user-attachments/assets/43d8296e-7b1a-4c4d-a2c5-ae6b73d8aa3c" />
7. En el repositorio abre `Settings` → `Pages`.<img width="1366" height="768" alt="Captura de pantalla (797)" src="https://github.com/user-attachments/assets/a3d990ab-b7ec-45a8-a1fc-6972d7de79f1" />
9. En `Build and deployment`, elige `Deploy from a branch`.
10. Selecciona rama `main` y carpeta `/(root)` y pulsa `Save`.
<img width="1366" height="768" alt="Captura de pantalla (798)" src="https://github.com/user-attachments/assets/60ab82de-3a47-463f-a6e9-107a05c9fdc3" />
11. Espera unos minutos y abre la URL que GitHub muestre. Añade esa URL real al README.
